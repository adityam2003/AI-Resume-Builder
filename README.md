# 🧠 AI Resume Builder – MERN Stack

A full-stack **AI Resume Builder** application that helps users create, optimize, and manage professional resumes with AI-powered suggestions.

This project is built using the **MERN stack** and demonstrates real-world full-stack development, authentication, REST APIs, and AI integration.

---

## 🚀 Features

- 🔐 User Authentication (JWT-based)
- 📄 Create & Manage Multiple Resumes
- 🤖 AI Resume Content Optimization
- 🖼 Profile Image Upload using ImageKit
- 🎨 Modern & Responsive UI (Tailwind CSS)
- ⚡ Fast Frontend with React + Vite
- 🌐 RESTful APIs with Express & Node.js

---

## 🛠 Tech Stack

### Frontend
- React.js (Vite)
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT Authentication

### AI & Media
- AI API (OpenAI / Gemini – configurable)
- ImageKit (Image upload & optimization)

### Tools
- Git & GitHub
- VS Code
- Postman

### 🧑‍💻 Installation & Run Locally
### 1️⃣ Clone the repository
```md

git clone https://github.com/adityam2003/AI-Resume-Builder
cd ai-resume-builder
```

### 2️⃣ Backend Setup
```md

cd server
npm install
npm run dev
```

### 3️⃣ Frontend Setup
```md

cd client
npm install
npm run dev
```
